# NetworkWalks – Week 3: Password Challenges and HexStrike AI

## Overview

This repository documents my Week 3 practical activities during the NetworkWalks Cybersecurity and Ethical Hacking training.

This week's activities focused on solving a password-related security challenge, exploring cybersecurity automation with HexStrike AI, and preparing Claude Desktop for integration through the Model Context Protocol (MCP).

## Activities Completed

### 1. Password Security Challenge
- Worked on a password-related cybersecurity challenge.
- Practised the importance of patience and selecting appropriate wordlists when working on password challenges.
- Successfully captured another NetworkWalks challenge flag.
- Gained practical exposure to password security concepts.

### 2. HexStrike AI Installation and Configuration
- Installed HexStrike AI in my Kali Linux environment.
- Set up a dedicated Python 3.12 virtual environment.
- Installed the required Python dependencies.
- Configured the HexStrike API server to listen locally on `127.0.0.1:8888`.
- Started the HexStrike AI Tools API server successfully.

### 3. API Server Testing
- Tested the HexStrike API health endpoint.
- Received an HTTP 200 OK response.
- Confirmed that the API server was operational.
- Verified that the server detected 60 available tools.

### 4. Claude Desktop and MCP Preparation
- Installed Claude Desktop on Kali Linux.
- Created the MCP configuration file.
- Configured the HexStrike MCP bridge to use the correct Python environment.
- Prepared the connection between Claude Desktop and the HexStrike API.

**Integration status:** Claude Desktop was installed and launched, and the MCP configuration was prepared. The final connection and tool-access verification are still pending.
